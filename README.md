# jasperlammers.com

Source of [jasperlammers.com](https://jasperlammers.com), the personal site of Jasper Lammers: essays, a record of things built and written, and project highlights.

Static site built with [Astro](https://astro.build) and Tailwind CSS, hosted on Cloudflare Workers.

```sh
npm install
npm run dev     # http://localhost:4321
npm run build   # into dist/
npm run check   # type-check
```
